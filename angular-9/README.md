# @stackline/angular-highcharts Angular 9 Playground

Real Angular CLI 9.1 playground for `@stackline/angular-highcharts@9.0.0`.

## Run

```bash
npm install
npm start
```

## What This Example Covers

- Angular `9.1.13`
- `@stackline/angular-highcharts@9.0.0`
- `highcharts@10.3.3`, the highest Highcharts line validated for Angular 9 without Webpack syntax-loader changes
- live StockChart candles with REST history and WebSocket updates
- dynamic module-backed charts updated through existing Highcharts instances
- static examples for common and Highcharts 10 module chart types
- tutorial panels for HTML, TypeScript, and CSS
